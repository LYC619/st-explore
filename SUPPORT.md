# Support / 使用反馈

Check the [usage guide](docs/USAGE.md) / [中文使用指南](docs/USAGE.zh-CN.md) and [deployment guide](docs/DEPLOYMENT.md) / [中文部署说明](docs/DEPLOYMENT.zh-CN.md) first. If you hit a reproducible bug, open an issue with:

- Build identity from **Settings → About & guides**
- Platform (Windows desktop, self-hosted web, or Android), OS/browser version, and interface language
- Minimal reproduction steps using a synthetic card or chat sample

Keep real chat logs, private character cards, API keys, and library backups out of public issues. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

中文：遇到问题可先查阅使用指南与部署说明；提交 issue 时请附上「设置 → 关于与引导」中的构建号、运行平台、界面语言及合成示例复现步骤，请勿上传私人聊天、角色卡、密钥或备份包。
