# 阶段复盘模板

命名建议：`YYYY-MM-DD-序号-主题.md`，例如 `2026-10-15-01-文件维护.md`。日期格式采用无歧义的年月日；一个可交付阶段结束时填写，建议控制在一至两页。此模板不是自动化任务，不会定时运行。

## 值得持久化吗

- 只影响本次：留在本记录。
- 是当前产品事实：更新 `CURRENT.md` 或相应功能文档。
- 在多个任务中反复成立、动作明确：考虑精简地更新项目 `AGENTS.md`。
- 已经重复使用且输入、步骤、产物稳定：再考虑 skill。
- 涉及全局偏好：先看跨项目证据，再决定是否进入全局规则或记忆。

每月回看时只回答三件事：哪种返工又发生了？哪条规则已过时？自己现在能解释哪个以前不懂的机制？不要求重读全部聊天。
