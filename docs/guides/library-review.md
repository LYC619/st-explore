# 用回顾视图整理游玩记录

进入角色库，点击顶栏「回顾」。也可以在「外观」菜单中选择回顾视图；再次点击顶栏「回顾」返回网格。

## 连续浏览

左侧选择角色，右侧查看总览、备注、故事、总结或日记。切换角色时保留当前页签：正在看总结，选下一张卡就接着看它的总结。重新选回之前的角色，会恢复本次应用会话内的阅读位置。

总结和日记默认覆盖这张卡下的全部故事，按故事和主线/分支分组，并直接展示全文。分卷总结按卷号、楼层排列；已经删除的分支留下的记录会明确标出来源。没有总结时保留当前页签，可点击「查看故事」。

搜索、标签和类型筛选仍然有效。桌面回顾视图的筛选栏默认收起，点击「筛选」展开；「仅有故事」可以隐藏尚未归档故事的卡。窄屏点击当前角色名称展开角色目录。

## 边看边整理

- 「备注」支持添加和编辑玩卡心得。
- 「编辑评分和标签」修改 STE 本地整理信息；评分与评价标签沿用角色详情的联动规则。
- 「故事」可以修改每段故事的游玩状态，或直接打开正文阅读。
- 需要深入编辑时，点击「打开角色详情」或故事阅读器里的「在编辑器中打开」。返回角色库后，原搜索、筛选和回顾位置仍会保留。

故事阅读中的收藏、设置和进度在切换前保存。保存失败会保留当前阅读内容并提示重试。阅读记忆按文件库隔离，关闭应用后重新开始；已有的故事楼层进度仍按原规则保存在档案中。

回顾视图只读取和展示已有总结、日记，不会自动请求 AI 生成新内容。
