# 界面翻译维护

[English](I18N.md)

当前界面支持 `en` 与 `zh-CN`。简体中文界面文案作为原文键，英文翻译存放在 `src/lib/i18n/locales/en.json`；`src/lib/i18n/index.ts` 负责语言识别、本地记忆、跨窗口同步、单次占位符插值与日期数字格式化，React 组件通过 `useI18n()` 订阅更新。

语言优先级：`?lang=` 地址参数 → 已保存的 `ste-language` 偏好 → 浏览器语言 → `en`。

## 新增或修改界面文案

1. 使用完整句子包裹 `tr('保存')` 并在 `src/lib/i18n/locales/en.json` 补充对应英文；含变量的文案统一写为 `tr('已选择 {{v0}} 项', { v0: count })`，不要把一句话拆成多段 `tr()` 拼接。
2. 渲染翻译文案的组件需调用 `useI18n()`（含 `React.memo` 组件）。模块级标签字典使用 getter（`get label() { return tr('...'); }`），不要在模块顶层把 getter 提前求值存死；依赖翻译结果的缓存计算使用 `useLocalizedMemo`。
3. 严守持久化与显示分离：状态枚举、标签原始路径、筛选键值、库内导出目录名必须保持固定原文，仅在界面展示时调用 `tr()`。
4. 角色卡、聊天记录、自定义标签、已保存名称、内置写作提示词及内嵌酒馆自身的语言体系保持原样，不随外层界面语言自动改写。
5. 提交前运行 `npm run i18n:check`、相关单测与 `npx playwright test --config=playwright.production.config.ts`，并在 390px 窄屏下检查英文按钮与弹窗排版。

## 扩展新语言

在 `src/lib/i18n/locales/` 新增语言目录，更新 `src/lib/i18n/index.ts` 的语言识别与 `LanguagePicker.tsx` 选项，同步扩充 `scripts/site/content.mjs` 及双向 `hreflang` 互链，并补齐浏览器切换用例。
