# 预设库与全局交互打磨

用户在 0.9.2 便携包真实使用后指出预设库拥挤、重复、手填过多，以及常驻批量选择圈、主题滚动条、角色信息栏与回顾备注遗漏。已显式创建持续 goal 并授权多 agent 自主实施、关联审查与挑剔试用。基线 `codex/playtest-1007@18e820e`；保留参考资料整理和共享 `.user`。

## 目标与设计方向

- 预设库升为角色库下面的一级入口；旧地址仍能打开，编辑器、选择器、首页与返回关系一起对齐。
- 收藏库以能浏览、识别、取用的系列／版本为中心。主页面只保留搜索、少量常用切换和导入；高级筛选折叠。无实际分组价值时不重复显示标题。
- 自动从文件名和明确配置识别模型、版本与名称线索；推断与用户确认的资料区分，不能猜作者、不能覆盖手工资料。已有预设不因缺少管理字段就满屏“未标”。
- 详情默认阅读说明和内容资源，点击整理后才展示表单；模型／用途等常用项可点选，保存、退出、版本切换与 DIY 保持清楚。
- 所有批量选择控件只在批量管理时出现；配置开关与导入勾选保持本义。滚动条统一适配四套主题。
- 角色信息折叠栏更窄，不露出该栏多余滚动条；回顾备注复用右侧切篇和标题目录。

## 分工

主 agent：预设体验、导航、集成、真实样本浏览器试用与交付。

`global_consistency`：除预设外批量模式审计实现、全局 scrollbar。

`notes_and_rail`：角色信息折叠栏、回顾备注与共享实现。

`preset_research_review`：同类项目观察、样本字段分析、关联入口审查和独立新界面评审。

## 验收与证据

1. 只读获取真实预设，放到隔离库，覆盖长名称、缺少资料、多版本、多模型及内嵌脚本／正则；不改真实来源，不执行附件脚本。
2. 真实 App：浏览、筛选、导入、自动识别、查看说明／附带内容、整理保存、刷新、取用和 DIY；四主题、窄窗口、200% 字体／缩放下排版与滚动。
3. 全局关联入口与批量退出、跨角色／跨库的备注状态逐项检查。独立评审列出实际难用之处并修复，不只截空页面。
4. 聚焦测试 → 集成／全量回归 → 生产与 Windows 构建；各运行边界分别记录，不能用浏览器断言冒充原生验收。
5. 形成可实测批次后交付双包、更新 CURRENT、技术记录和一批共享阅读档案。保留上一包与非本轮用户资料。
