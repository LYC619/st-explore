# 10 月 5 日实测优化设计

用户已授权自主规划和实施。沿用现有归档与酒馆运行时，以恢复连续阅读、整理和续聊的实际流程为目标。

## 阅读与正则
总览备注、总结采用 Markdown 正文，子卡限制最大高度但允许滚动；详情备注、总结、日记同样渲染 Markdown。回顾页角色标题和标签随正文滚动，保持原阅读进度恢复和离开前保存保护。正则栏高度跟随可用视口，底部按钮可达。消息时间显示年份；故事列表显示完整游玩日期。

正则使用 SillyTavern minDepth/maxDepth：最新消息为 0，最近 N 楼为 maxDepth=N-1，最近 N 楼以外为 minDepth=N。深度按完整会话计算，过滤和选择导出范围不改变深度；纯文本工具提供测试深度。旧 _raw 深度兼容，清空范围不会复活旧值。书签列表提供独立删除按钮，不跳转、不删正文，保存失败维持可重试状态。

## 导出与世界书
角色操作菜单明确区分原格式与 JSON 导出，JSON 保留卡片扩展字段。故事列表导出菜单直接提供 JSON、SillyTavern JSONL 和高级导出；分支可指定导出，默认使用明确显示的主线，不混淆当前阅读内容。导出保留消息元数据、当前正文、候选与隐藏状态。

世界书 UID 可编辑为非负安全整数，占用时显示错误。保持内部稳定条目 key，避免选中条目和批量操作引用失效；导出以更新后的 UID 重建 ST entries 键。排序明确显示 UID 升序/降序，避免把 UID 误称创建顺序。保存、重新打开和导出后值一致。

## 聊天与美化
聊天生成必须取当前故事分支的会话上下文，切换不覆盖其他分支。分支选择和脚本设置在聊天顶栏可发现；脚本面板显示启用、运行或错误状态。角色详情中的故事/分支可直接续聊，导航前保存阅读状态，不复制故事。

编辑区新增美化页，围绕当前故事配置和预览状态栏、悬浮状态栏及 MVU 变量显示。复用现有脚本/HTML 沙箱与权限配置；允许导入现有脚本并查看兼容性。内置模板必须可保存并在聊天里生效。不能把简单变量显示称作完整第三方 MVU 引擎；支持范围和需要的运行时设置在使用位置说明。

## 验证与交付
数据逻辑先写失败回归再修复。浏览器使用独立样本验证滚动、Markdown、导出、UID、分支继续与脚本状态，含桌面和窄屏。通过定向/全量测试、TypeScript、lint、生产构建和独立审查后，本地提交并打 Windows 包。保留原工作区其他改动，不推送远端。
