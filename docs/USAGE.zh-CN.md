# 从一张卡、一个故事开始

[English](USAGE.md) · [部署说明](DEPLOYMENT.zh-CN.md)

了解 ST Explorer 的导入、阅读、续聊、备份与语言切换。

## 1. 先安放藏书馆

可使用桌面版本，也可打开自己部署的网页版。桌面端选择一个本地文件夹作为藏书库；网页版按站点域名和浏览器配置分别保存资料。

## 2. 选好界面语言

打开「设置 → 显示 → 界面语言」，可在简体中文与英文之间切换。角色卡、聊天记录、自定义标签、已保存名称、内置写作提示词以及内嵌酒馆自身的语言设置保持原样。

## 3. 导入第一张卡

进入「角色库」点击「导入」，先导入一张 PNG 或 JSON 角色卡，再导入配套聊天记录。桌面端扫描 SillyTavern 目录时全程只读，不会改动原目录。

## 4. 阅读和整理

打开角色并选择故事，进入页内阅读或聊天处理工作台。可以搜索楼层、调整正则、标记章节并保存修改；导出会生成独立副本，写回原文件需手动确认。

## 5. 继续一场戏

先在「设置 → AI 配置」填好模型服务，再从故事点击「继续聊天」。网页版需确认所选模型服务允许浏览器跨域请求。

## 6. 留好备份

大批量导入或升级前，可在「设置 → 数据与备份」导出整库备份；桌面文件库建议另留一份文件夹备份。网页版更换域名或端口会切换到新的浏览器存储空间。

## 常见问题

### 换网址后资料为空

回到原网址在「设置 → 数据与备份」导出备份，再到新网址导入恢复。

### AI 请求失败

在「设置 → AI 配置」检查接口地址、密钥和模型名称；网页版还需确认提供商支持浏览器跨域调用。

### 升级后页面空白

先保存正在编辑的内容再刷新，检查静态资源与内嵌酒馆文件是否已整套同步部署。
