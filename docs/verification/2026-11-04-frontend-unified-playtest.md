## 使用变化

以前的美化页主要配置字段模板，无法直接编辑用户已经做好的一整套 HTML。现在从“功能扩展 → 前端美化”进入，默认使用“成品前端”，原来的“字段模板”仍可切换。

选择故事／分支后，可读取角色原有正则和脚本，或添加 HTML、JavaScript、脚本／卡片 JSON、示例变量及说明材料。支持编辑 HTML、正则名称／匹配／深度／启用范围与脚本源码；保留原正则顺序、placement 和未知字段。桌面左右编辑／预览，窄屏切换；示例变量或选定楼层／候选的快照只用于预览。

“保存草稿”和“应用到当前故事／分支”分别保存。草稿重进恢复，未保存切页有提示；聊天只使用最后一次应用的副本，可撤下。应用前校验目标故事、资源、助手设置和草稿基线，生成中禁止编辑应用。库切换沿用实际运行目录与 epoch 检查。普通应用不改角色卡、主世界书、共享正则或故事变量。

## 运行与持久化

- 工作副本保存到各故事 `.ste-control/roleplay/<branchKey>/frontend.json`，包含独立 draft 和 applied。可导出／重新导入工作副本；重新导入的脚本默认停用。
- 明确应用的分支正则可独立生效，修复原卡没有内嵌正则启用提示时，新建 HTML 被原开关挡住的问题。已应用规则不再重复弹出原版启用询问；其余源卡正则继续遵循原版开关和提示。
- 原版助手以完整 HTML 文档识别可运行前端，因此新建和导入片段补齐文档结构。聊天绘制前载入分支规则；APP_READY 晚于首屏时按规则变化补绘，从美化返回常驻聊天时刷新已应用内容。
- 启用的配套脚本交给已安装的原版酒馆助手 4.11.3。运行身份包含故事／分支摘要，退出或换分支后不会泄漏到全局持久脚本列表；递归清理文件夹中的临时脚本。
- 原版助手脚本变量写入 applied 副本，草稿保持不变。重新应用 HTML 保留同 ID 的脚本状态。补测捕获并修复初始化 CHAT_CHANGED 刷新覆盖刚写入变量的竞态；同分支刷新保留正在运行的变量，不带到其他分支。
- 应用基线只纳入实际助手包和脚本开关，不因酒馆后台自动保存无关 UI 设置产生冲突；故事、资源和工作副本的真实变更仍要求重新载入。
- 可分享故事包省略可执行 frontend.json，沿用 helpers.json 的现有规则。新分支不自动继承可执行前端配置。
