## 退出路径检查

- `ClientTitleBar` 使用 Tauri `window.close()`，无自定义隐藏到托盘。
- `Roleplay` 的 `onCloseRequested` 先拦截并执行 `saveBeforeExit`；保存成功后置 `allowExit` 再关窗。Tauri JS helper 在事件未被阻止时调用 `destroy()`，现有 capability 允许该命令。
- `WorldPlay`／`GalPlay` 也有停止当前操作、等待持久化再关闭的钩子；本轮未验证其长任务关窗，不按通过列入。
- Rust `Builder.run()` 使用默认退出行为，没有项目自建的 `prevent_exit`／隐藏窗口退出钩子，没发现本项目生产路径启动的常驻子进程或 TCP 服务。本轮没有据源码扫描断言所有第三方插件均无后台活动。
