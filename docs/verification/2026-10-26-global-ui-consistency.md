# 2026-10-26 全局批量管理与滚动条一致性检查

执行：Codex 子 Agent `global_consistency`。本记录仅涵盖全局选择控件和滚动条；预设库、导航、备注及信息栏由同批任务的其他执行者负责。

## 使用问题与调整

- 角色详情的总结／日记列表原先常驻选择框，还显示不可用的“加入世界书（0）”。现在普通浏览隐藏这些控件，点“批量管理”后才显示选择框、当前记录全选和已选数量；有选择时才出现世界书操作。批量模式点击卡片可选择，正常模式仍可展开正文、移动及复制记录。
- “完成”退出批量管理并清空选择；切换故事、总结／日记或故事脉络也会退出，记录消失时剔除失效选择。未关联角色的故事没有可执行的世界书批量动作，因此不显示空的批量入口。
- 立绘原先切换角色时可能保留批量状态和前一角色的选择。现在切换角色或数据仓库时一并清空批量、选择与移动弹窗状态。
- 角色库、立绘、世界书的批量退出文案统一为“完成”，角色库和立绘入口提供 `aria-pressed` 状态。
- 原先只有少量自带 `scrollbar-thin` 的容器适配主题，普通溢出容器和原生控件可能露出白色滚动条。现在全局原生滚动条、已有细滚动条以及 Radix ScrollArea 共用主题滚动条 token；轨道透明，滑块取当前主题的次级文字色。三套深色主题使用 `color-scheme: dark`，米色主题使用 `light`。角色库原有滚动时显示、闲置时隐藏行为保留。

## 边界与用户视角意见

本子任务没有执行完整构建、全量测试、Tauri／便携包或 Android 验证，不能据此声称它们通过。浏览器证明了实际 Web 入口和四主题样式，原生滚动条最终细节仍受平台和 WebView 版本影响；后续便携包验收应查看 Windows 上的最终外观。隔离 iframe 有自己的文档和主题，不由宿主页通用滚动条样式覆盖。

从浏览记录的角度，常驻选择圈与零选择按钮是无效干扰，现已去除；显式批量入口、已选数量和“完成”使当前状态可见。清空选择同时覆盖跨故事／角色切换，避免只改外观而保留旧选择。记录卡正文较长时仍按原有四行摘要展示，这是阅读设计的后续取舍，本次没有把局部选择问题扩大为记录页重排。
