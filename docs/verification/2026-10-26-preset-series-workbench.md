## 使用变化

| 原来怎样影响使用 | 现在怎样 |
| --- | --- |
| 名称、作者、系列混在一起，列表不便整理 | 独立名称；系列默认作者且可修改，同作者同系列聚合；卡片提供说明与笔记摘要 |
| 批量选择依赖小圈，整理项目过多 | 批量状态点整张卡片选择；统一模型、作者、系列、标签四项操作；旧用途／状态值保留，移除编辑入口 |
| 模型与标签不便集中管理 | 左侧模型分类和独立分组标签；增改删、重命名与关联项同步；明确清空模型后不再被文件名自动补回 |
| 预览和完整编辑挤在同一区域 | 普通点击进入 `/presets/:id` 系列详情；预览模式在列表右侧快速查看；左侧资料与版本，右侧关于／内容／附件／试用 |
| 预设需要离开库才能简单试用 | 显式发送、局部模型选择、角色与世界书挂载；标签往返保留临时对话，切版本／离开／刷新清除，不写角色故事 |
| 切服务或常用模型要反复进设置 | 按已保存服务分组的快捷切换，设置管理常用模型，“管理服务”直达 AI 配置 |
| 角色折叠入口额外占顶部一排 | 信息栏右下角小箭头；收起宽度 36px，展开保持滚动和键盘操作 |
| 200% 缩放下详情顶部占太多空间 | 窄屏只保留紧凑版本区；桌面仍显示完整左侧资料 |
| 阅读日志把页面名当更新内容 | 模板显示实际功能／体验变化，另列页面与修改定位；既有日志更正保留原 ID、日期与历史 |

范围保持现有来源只读、导出副本、DIY 派生及持久化边界。不执行附带脚本，不自动迁移个人笔记，不把试用当完整 ST 扩展宿主。

## 整合时查出并修复

- 文件库的 archiveMeta 只有一个 `库信息.json`。独立写入 `preset-tags` 会覆盖 schema、库标签与游玩偏好；改为 archive-schema 内 `presetTags` 字段并复用元信息写队列。实际文件后端回归覆盖并发保存、重开、重命名／删除以及切库隔离。
- 增加模型人工确认标记，区分“没有线索”和“明确清空”；导入的共同模型修改与逐项修改按实际操作优先级保存。
- 新版导入成功后先解除导入草稿状态再导航，避免成功后仍被离开保护拦住。未保存版本切换继续提示。
- 试用采用访问后挂载并隐藏的标签内容，避免切回关于后丢失临时对话；版本和资料库变化仍清理并中止请求。
- 全局搜索展示独立名称并进入新详情路由；三个图标按钮复用统一尺寸。

相关入口：`src/pages/PresetLibrary.tsx`、`src/components/preset/PresetCatalogDetails.tsx`、`src/components/preset/`、`src/components/ai-tools/QuickModelSwitcher.tsx`、`src/lib/archive-db.ts`、`src/lib/preset-tags.ts`。精确文件以 `83c98ec` 与 `ba81eb7` 提交为准。
