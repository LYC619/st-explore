# 0.9.3 预设库体验与全局交互交付

用户在 0.9.2 便携包实测后否定预设库的排列、筛选与手填负担，并指出一级入口、批量选择圈、主题滚动条、角色信息栏和回顾备注遗漏。本轮重新打磨实际浏览与取用过程，参考同类项目并使用真实预设的隔离样本检查，三名子 Agent 分别承担全局一致性、备注与信息栏、研究和独立挑剔试用。

## 已实现

| 使用阻碍 | 现在的行为 |
| --- | --- |
| 预设藏在附属库，页面像字段表 | 角色库下面直接进入预设库；系列卡片聚合版本，可切紧凑列表 |
| 大量筛选常驻、空资料反复提示未分类 | 搜索、收藏、DIY、模型快捷切换放主页面，高级筛选放弹出面板 |
| 导入前就要填写一堆字段 | 先选 JSON 和随附文件，识别版本、系列、模型及 MD/TXT 说明，再确认入库 |
| 想看说明却先面对编辑表单 | 默认只读概览／内容／附件；“整理资料”展开表单，模型与用途可以点选 |
| 多个入口展示旧名称或找不到模型 | 共享名称及识别线索，搜索、AI 挂载、编辑历史、角色关联资产一起对齐 |
| 普通浏览满是选择圈 | 批量管理才显示选择控件；完成、切类别／角色后清空相应批量状态 |
| 深色主题白滚动条、折叠信息栏过宽 | 四主题统一原生和组件滚动条；折叠栏 36px，展开仍可滚动但不显示轨道 |
| 角色库回顾备注没有右侧目录 | 与角色详情共用切篇／标题导航和大备注编辑器，跨角色／跨库状态隔离 |

原有来源、库内文件、工作副本和取用副本边界不变。导出到作者／系列／版本文件夹或 ZIP；编辑区可改原版或复制 DIY，不执行附件脚本。

## 独立挑剔试用及修复

| 实际发现 | 处理与复测 |
| --- | --- |
| 60 份来源中 46 份保留多个供应商模型字段，直接收集会误标 | 文件名明确线索优先；只读取当前供应商模型；手工资料优先，不猜作者。名称识别及选择器测试通过 |
| 两份同版预设按钮都叫 3.10 | 按变体或“文件 1／文件 2”区分；点击后核对真实记录 ID、正文和 URL |
| 旧预设没有 catalog，DIY 生成另一张系列卡 | 复制采用原版的展示系列，附件和原版不变；再次复制不会叠加 DIY 标签 |
| 导入新文件后详情已换，URL 仍指旧记录 | 导入、卡片选择与关闭同步选中参数；完整刷新和同路由连续搜索实测 |
| 换文件之前只改作者，换后却沿用旧版本和模型 | 逐字段保留人工修改；其余线索随新文件刷新，含说明和单份／多份切换 |
| 手机详情被列表工具挤到下半屏 | 进入详情收起列表工具；390px 示例详情空间由约 385px 增至约 605px，说明、保存、导出与返回可达 |
| 真正 200% 缩放时弹窗标题被导航挡住 | 网页导航降到弹窗下面，导入弹窗为原生标题栏留空间；标题／说明／关闭无覆盖，重开、填写、导入成功 |
| 未保存时搜索另一份预设可能丢编辑或提示两次 | 同路由使用单次放弃保护，取消恢复原 URL 和输入，放弃不写入旧草稿 |

试用仍有明确限度：同版多文件能分别查看，但没有并排正文差异；作者无法可靠自动识别；模型线索不代表真实效果测试。上述三项不是本次实现完成的功能，版本比较、每模型试用档案和笔记迁移继续后置。

## 验证依据

- 实样：本地只读取得 15 份真实预设，约 9.5 MB，隔离库中聚合为 11 个系列；覆盖缺资料、长名称、多版本、正则和脚本。最终核对 15 个来源 SHA256 全部未变；未上传样本正文。
- 真实 App 浏览器：预设流程 4 组、导航 6 组、备注／信息栏 4 组、全局批量／主题 2 组。覆盖导入、自动填写、说明表格、资料保存、版本切换、ZIP、DIY、旧地址、搜索、角色上下文、四主题与窄屏；各组无 pageerror。
- 独立复测：正常视口及实际浏览器 200% 各 6 组行为。1440×960 窗口放大后为 CSS 720×480、devicePixelRatio 2、CSS zoom 1，实际完成键盘操作、滚动填写、持久化核查和 ZIP 下载。最后另验证弹窗无遮挡。
- 集中回归首轮发现冗余按钮高度，与既有控件栅格约束冲突，删除重复定义；后续全量发现网页导航旧 z-index 静态断言，根据真实弹窗复现更新。没有用 mock 或字符串存在代替交互证据。
- 全量、生产构建和打包最终结果见下方交付表及包内清单。

分项记录：[研究、旧失败与独立复测](../superpowers/plans/2026-10-26-preset-experience-research.md)、[导航与搜索](2026-10-26-preset-navigation.md)、[全局交互](2026-10-26-global-ui-consistency.md)、[回顾备注与信息栏](2026-10-26-review-notes-rail.md)。
