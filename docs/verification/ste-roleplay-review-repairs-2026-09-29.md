# 2026-09-29 游玩审查修复记录

本轮接续 9 月 18 日审查。核对 Claude 会话、Git 和源码后，确认此前仅修正了导航测试断言，业务问题尚未修复。本轮在 `codex/ste-roleplay-runtime` 工作树修复，原主目录的参考资料删除、未提交文件和忽略规则另行保留。

## 已修复

- **H1：取消与超时。** 等待后台记忆时，取消当前发送立即结束等待，不撤销已保存回合的记忆工作。一次工具 Agent 循环总限时 120 秒，覆盖请求及响应正文；底层忽略取消时也拒绝迟到结果，并释放计时器和监听器。
- **H2：失效方案重试。** 记忆版本不匹配或目标变为手动笔记时，将维护记录持久标记为需要重新规划。重试（包括重开后的重试）读取当前资料，使用新的记忆事务身份，保留手动笔记。暂时性写入失败继续沿用原事务恢复；已提交事务不会重复执行。真正未解决的多文件冲突仍要求手动确认，不自动覆盖。
- **H3：旁白往返。** `/sys` 旁白和评论的隐藏状态独立于 system 角色，保存、重开、隐藏与取消隐藏保持原语义。STE 原生系统消息、候选身份和插件字段保留。
- **M2：历史变更取消生成。** 每次请求在异步准备前捕获其源历史；保存对该前缀的编辑、删除、重排、隐藏或候选变化时取消旧请求。纯元数据修改和正常追加输出不取消，swipe/continue 的目标尾部更新仍正常。
- **重新生成的源历史。** 上游 regenerate 已删除待重生的回复，宿主不再额外删除前一条 assistant 消息。
- **Unicode 引用截断。** 按 token 预算选择原文的完整 Unicode 字符前缀，不再解码半截 token；分页引用、偏移和正文保持一致，避免引入乱码。

新增测试先在旧实现上复现失败，再验证修复；原有导航断言从四区改为包含聊天的五区，并纳入本次提交。没有修改固定上游 vendor 文件或扩大原生权限。

## 复核后保留的边界

- 重复消息 ID 仍拒绝保存：现有支持的复制入口会分配新身份，不能无条件给重复项换号而移动收藏、分支或记忆归属。
- 并发版本冲突仍拒绝覆盖，现有独立恢复导出、退出和重开路径保留。
- 损坏世界书版本仍显示具体文件错误并停止生成；跳过已接受版本会静默改变世界设定。修复文件后重读。
- 保留用户配置的局域网模型接口，不按报告建议将 HTTP 限制到 localhost。
- 故事包对疑似凭据/本机路径的严格校验可能误拒剧情笔记，仍是已知可用性限制；不能为绕过它而修改恢复日志或静默丢弃整套记忆。
- 非 OpenAI 模型 token 估算、swipe 后缓存周期重建、故事包作为副本导入及更多插件能力，仍按已有兼容范围处理。未宣称标签化资料可以彻底防止模型提示注入。
