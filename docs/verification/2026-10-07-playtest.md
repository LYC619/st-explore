# 2026-10-07 实测反馈修复

## 对应反馈

1. **生成 swipe 时的保存报错**：原版先把候选下标移动到数组末尾，完成后才填入候选。保存编解码器现在只在克隆快照中补齐这一合法临时位置；原候选不变，负数、跳号等损坏数据仍报错。覆盖生成进行中的普通保存和草稿恢复。
2. **加载与内存**：取消启动后的全页面预加载；远程字体 CSS 改为非阻塞，离线时先用本地回退字体。减少聊天目录重复读取，宿主只保留角色必要字段，关闭后清空缓存。未测量真实 WebView2 进程的内存峰值，不能给出 MB 或百分比承诺。
3. **常驻聊天**：按用户选择实现应用内后台聊天。切换其他模块时保持一个酒馆实例和正在生成的请求；任务区可随时返回。保持隐藏 iframe 的布局尺寸，避免原版虚拟列表停止刷新。关闭聊天释放资源，切换另一会话前先保存，切换资料库隔离旧任务。
4. **角色筛选标签**：去掉顶部重复已选标签行，侧栏再次点击取消；兼容旧筛选值。
5. **重复正则**：补上新导入的内嵌来源关系；已有资产依据来源识别，兼容原规则没有 ID 的情况，只移除对应副本，保留独立规则。角色卡同步导出使用同一判断。
6. **图床预设与下载**：新增 Catbox 世界书列表快捷规则，使用本轮提供的表达式与模板，保持 URL 编码原值。最多四个并发下载，逐张串行提交角色更新；关闭弹窗、切页后继续，可停止、查看失败和重试。角色、分行及资料库固定，下载完成不会覆盖同期角色修改。
7. **返回聊天处理**：返回当前 `/chat` 工作台，带上故事与分支。补上分支加载、绑定和润色定位；仅打开处理页不会回写旧正文，同页连续保存排队，外部新回复冲突明确报错。
8. **未评分**：评价入口增加真正的未评分筛选。没有数字评分的导入角色可以直接找到；已有低于 6 分的数值保留，显示为“6分以下”，旧“低创”仅作数据兼容，避免将已有评分伪装成未评分。
