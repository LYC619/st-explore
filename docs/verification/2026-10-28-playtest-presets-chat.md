## 独立审查与追加修复

实现由主 Agent 与三个分工 Agent 完成，随后由非实现该部分的 Agent 独立只读审查。对具体链路重新核实，未仅凭建议直接改动。

- 返回刷新不提前清空角色身份缓存，防止并发角色保存被误判为合成角色并虚假成功；新增延迟目录读取与并发真实保存回归。
- 背景刷新不推进预设编辑基线；显式重新选择时用对应菜单 revision 确认新基线，既拒绝旧草稿覆盖，也允许重选新版后保存。
- 不调用上游会重新选择角色、重填编辑表单的 `getCharacters()`；只刷新标签并重画列表，保留角色表单草稿。角色实体新增、删除和名称变化需重新进入聊天加载。
- 新导入版本沿系列共享队列继承标签；导入窗显式改标签时同步系列，防止过期系列因新版本入库重新出现在酒馆菜单。
- `[DONE]` 后连接仍打开时，不再把已完整回复误判为闲置超时；终态、空回复和取消分别验证。
- 返回列表时清理已删除预设的选中状态，保留其他筛选。
