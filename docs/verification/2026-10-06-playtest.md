# STE10.5 实测修复与资料导入

基线 `8721315`；单代理执行；所有改动在 `ste-roleplay` 工作区完成，未更改 vendor 原件。

## 用户可见变化

- 预设的提示词后处理支持原版 merge、semi、strict、single 和保留工具调用的变体，包含媒体内容和说话人名称。Agent 插入资料后再处理，保证最终请求一致；自定义 YAML 覆盖仍遵循上游顺序。
- 普通预设导入不再误报 Agent Skill 失败。确有 TauriTavern 专用技能时保留数据并说明尚未执行。
- 原生用户设定管理可以新建角色并保存头像，刷新后恢复；支持删除和自定义图片头像上传。
- 标签默认单行，点击展开；快捷添加包含其他角色已有的自建标签；从详情返回库保留排序、筛选和搜索。
- 编辑区聊天记录支持 Markdown、引号对话强调、代码块、列表、表格及搜索高亮。原始编辑文本和导出不变；正则预览仍按原始匹配展示。
- 立绘页新增「从图床导入」：按行/正则提取、捕获组拼接、URL 编码、预览选择、逐张保存、取消和重试；单图 20 MB、单批 1000 张；正则在可终止的 Worker 中运行。
- 可安装固定版本的原版酒馆助手 4.11.3，加载其原版界面、脚本库和 API，停止内置精简助手。接入原 ChatSurface 以支持虚拟聊天列表。
- 聊天页后退会先保存编辑内容；同一次后退只放行一次，保存引起的分支地址同步也不会再取消后退。写入失败时仍可重试或导出恢复文件。

## 真实资料导入

源笔记与附件目录只读。人物 0–5 对应的 38 个已有角色保护跳过。先生成匹配清单，再通过真实仓库实现写入独立暂存层，检查所有既有字段，最后按哈希清单发布。

正式库从 85 个角色 / 146 个故事增至 131 个角色 / 215 个故事：新增 46 个角色、69 个故事，为 26 个已有角色追加资源，保留 315 份原始附件，解析 56 份世界书和 32 组正则。原卡版本作为附件保存，已有卡片、标签、评分、笔记、总结、故事与库设置未替换。

核对 1,628 个原有文件：仅 26 个档案 JSON 增加附件/资产引用，其余保持原哈希；这 26 个档案除追加字段外也逐字段一致。4 个没有对应笔记的附件目录未自动归属；4 份无对应卡目录的笔记另存说明目录。目标库说明文件含逐项清单，库外备份含原档案、库信息、全部哈希和发布日志。再次只读扫描待新增角色/聊天均为 0。
