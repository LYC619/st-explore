# 2026-09-12 STE 游玩功能工作汇总

今天完成了从方案落地、原版酒馆接入到 Windows 试玩反馈修复的一轮开发。当前可以从独立聊天入口选择角色开始游玩，使用原版 SillyTavern 操作界面，并按需要选择 STE Agent 或柏宝书维护记忆。

全部工作位于隔离工作树的 `codex/ste-roleplay-runtime` 分支。功能、修复和既有说明已形成 13 个本地提交；本汇总另作一次文档提交。未合并或推送，原工作区的用户修改保留。

## 今天完成的功能

1. **确定方案并接入原版界面。** 采用固定版本 TauriTavern / SillyTavern 前端，保留熟悉的抽屉、消息编辑、候选切换、预设和世界书操作。STE 接管资产、模型配置、故事与分支保存；上游文件保持原字节，适配通过可校验的覆盖层完成。
2. **把已有资料接成可以游玩的故事。** 角色卡开场白、新聊天、原有故事、分支、候选与编辑都进入同一套 STE 保存流程。补上资产稳定身份、别名归属、编译缓存路径和开发模块请求方面的接入问题。
3. **实现两种模式与文件记忆。** 无 Agent 模式使用原酒馆流程；Agent 模式由主模型负责正文和窗口内的长历史，工具 Agent 自动查阅世界书、Markdown 记忆与必要历史，提供资料及文风、剧情提醒。成功回复保存后才维护事实记忆；每轮补充资料固定后追加，减少反复改变历史前缀。
4. **实现分支记忆和世界书版本。** 分支继承截至分叉点仍有依据的记忆；正文编辑或候选变化会重新校验来源。世界书变化生成可查看、接受的版本草稿，原资产保留。
5. **接入常用助手能力和柏宝书。** 内置部分脚本、变量、事件、消息操作、HTML 交互和辅助生成能力。固定版本柏宝书 1.2.7 的安装、非向量摘要、台账、隐藏与注入、重开、候选归属和记忆维护者切换已有验证。柏宝书由用户导入插件 ZIP，兼容范围不等于完整酒馆插件生态。
6. **补齐迁移与恢复。** 支持 JSONL 聊天互操作和包含分支、资产、文件记忆的 `.ste-play` 故事包。保留草稿恢复；新增保存失败时的独立恢复导出，能带走当前编辑、候选、插件字段及未发送输入。
7. **按试玩反馈调整体验。** 新增桌面侧栏和移动导航中的独立“聊天”模块，支持搜索、继续和选择角色新开聊天。增加首次指南、常驻“玩法设置”和“使用帮助”，说明模型、Agent 与柏宝书，并直接打开实际设置抽屉。

## 修复 Windows 试玩中的卡死问题

用户截图中的主要错误已经在实际 Windows WebView2 窗口中复现：文件写入成功后，缓存仍可能保留旧数据，下一次保存因此被误判为并发修改。通过缓存版本与写入结束后的失效处理修复，并保留真正的数据冲突保护。

原版错误处理还丢掉了具体原因，界面只有空泛的 `Error`，同时离开操作一直被失败保存挡住。现在显示实际错误，并提供重试、导出及确认后退出；用户此前点击的是关闭窗口时，确认后执行关闭。

原生验收另外发现并修复了三个问题：导出到文件库以外的位置失败、自定义端口的模型接口被权限范围拒绝，以及 Tauri SDK 缺少完成窗口关闭所需的权限。

实际文件占用造成持续写入失败时，未保存的编辑和输入仍能读取；确认后可以返回聊天列表或关闭窗口，原故事文件保持不变。
