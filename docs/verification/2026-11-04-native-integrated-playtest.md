## 实测发现与修复

1. 新建 HTML 规则漏了原版正则引擎需要的 `trimStrings`。遇到替换内容中的 `$1` 等字符时，实际 WebView2 弹出“聊天 DOM 虚拟化已停止”，错误为 `Cannot read properties of undefined (reading 'forEach')`。新建规则补默认值，旧工作副本在运行时补齐，来源文件和原副本不被重写。使用原版替换函数的回归先复现同一错误，再通过。
2. 直接导入 HTML 中的 JavaScript `$1/$2` 被正则捕获替换误读，可能破坏脚本。由“新建 HTML”或 HTML 文件导入生成的规则现在按字面使用 HTML，原有导入正则仍保留捕获组语义。固定上游源码保持原样，仅通过已校验的 host overlay 接入；实际替换函数同时验证两种行为。
3. Reborn2.3 的 SPreset 可以从模型 `tool_calls` 中提取正文。此前真实正文已经写入故事，“过程”却因没有直接 `content` 而标成失败。现在识别完整工具调用，分别记录“模型工具调用接收完成”及后续正文／变量保存；流式字节不改写，SPreset 仍负责提取。分块参数、非流式、损坏／未结束参数有回归；取消与过滤失败仍按失败处理。
