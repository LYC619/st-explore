## 提示词接线与数据边界

默认文本集中在 `src/lib/builtin-prompt-defaults.ts`；`builtin-prompts.ts` 负责读取、保存、恢复、占位变量的一次替换。运行时读取覆盖值，不把用户设置固化在模块初始化常量里。

| 模块 | 覆盖内容及生成入口 |
| --- | --- |
| 角色档案 | 简介、评分立场、5 个维度说明、评分输出格式和资料包装；`buildIntroMessages`、`buildRatingMessages` |
| 整理与记录 | 分卷、日记、DIY、小说化模板，结果微调、快捷要求、前情／世界书包装、指定日记主人；模板 getter、总结引擎、整理工作台与批处理共用 |
| 世界书 | 条目改写、快捷要求、增量提取及资料包装；`AIRewriteContent`、`AIUpdateDialog` |
| 预设 | 提示词块改写和快捷要求；`PromptEditor` → 通用改写入口 |
| 故事树 | 填树系统指令、树／正文／额外要求包装及历史定位说明；`buildTreeFillMessages`、`buildScopedTreeRequest`、`AIFillDialog` |
| 小说阅读 | 章节边界及标题指令、抽样／总结说明；`buildChapterSuggestMessages`；按章润色使用前述小说化模板 |
| 通用改写 | 当前正文和修改要求的包装；通用改写请求即时展开 |
| 继续游玩 | 生成前检索、采用后记忆整理、工具说明、工作要求、背景／建议包装和无资料提示；工具循环、上下文台账 |

- 设置属于当前设备的应用偏好，跨资料库使用，存 localStorage；不进入来源 ST 文件、库内作者预设、自定义模板或资料库备份。页面已说明这个边界。
- 世界书 `st-wb-update-prompt`、故事树 `st-story-tree-fill-prompt` **直接复用原键**，不会复制出两份冲突配置；旧文本照常读取，恢复默认不会让旧覆盖值再次出现。原弹窗保留本次输入，新增“保存提示词”后与设置共用；不再每次按键自动保存。
- 设置编辑草稿先存本窗口 sessionStorage，并保留会话内存副本；切模块或离开设置不自动生效。保存失败显示错误，保留输入；另一入口修改已保存值时保留当前脏草稿并提示差异。关闭窗口会结束草稿会话。
- 结构化输出条目保存时检查必要字段／变量存在；这不是对模型输出质量的保证。工具名称、JSON 参数结构、权限和预算仍由代码限定，改文案不扩大工具权限。
- 导入角色／预设的原提示词、用户自建模板和内嵌酒馆自身预设由各自编辑入口管理；连接测试的 `Hi` 与协议补位不作为生成任务指令列入目录。未修改第三方酒馆源码。
- 总结模板在新建或重新选择时读取设置。已有记录和当前正在编辑的模板继续使用原快照；需要新设置时重新选择内置模板。AI 评分保存生成当时的实际系统提示词、模板和模型快照，后续切模板／模型不改变这次结果的来源记录。
