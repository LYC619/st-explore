# 删除角色与所属内容

2026-11-10 按用户明确决定调整角色删除：角色名下故事、分支、总结、日记、故事树、运行文件、立绘与附件一并移出活动库。原来的“自动转为未绑定”不再用于角色删除。仅单独删除故事仍沿用既有记录保留策略，本批没有扩大改变。

文件库使用同一份可恢复移动清单保存完整角色组。删除途中失败恢复到原位置；确认成功后同步清理所有子记录的当前索引，重开也不残留。恢复时同时恢复角色、故事和记录的归属及索引，不需要重新启动应用。

共享世界书、预设、正则留在独立资产库；被其他活动记录引用的角色目录文件也保留。导入来源 `sourcePath` 不授予删除权限，源收藏目录不动。预览数量是目录范围提示，执行时重新核查共享引用与未完成恢复操作。

文件库默认进入既有30天回收流程；用户关闭“同时删除STE库内文件”时长期保留，仍可在设置中恢复。纯浏览器库没有文件回收区，使用一笔数据库事务移除角色和全部子记录。

证据及本次真实库归并另见[整理收尾](../maintenance/2026-11-10-library-finalize-and-fixes.md)。真实库归并只移走已迁移完故事的旧卡，并长期保留；不是对全部重复项执行无条件删除。
