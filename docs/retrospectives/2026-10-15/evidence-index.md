# 证据索引

本文保存支撑复盘所需的短引文和定位信息，不复制完整私人聊天。日期为北京时间；用户粘贴的 AI 审查与助手完成报告分别标明。编号在本次复盘中固定。

## 阅读方式

- `C`：聊天中的具体消息。会话链接加消息 ID、日期定位；不根据会话标题推断内容。
- `N`：用户提供的笔记；同一篇可能同时包含原始实测和助手总结，不能整篇当作用户原话。
- `G`：此次本地 Git 实际可解析的提交。提交证明代码历史，不单独证明用户验收。
- `R`：现行仓库文档或有明确来源的历史摘录。测试结果保留其原日期和限制。
