# Translating the interface

[简体中文](I18N.zh-CN.md)

ST Explorer supports `en` and `zh-CN`. Authored Simplified Chinese UI copy serves as the source key, with English translations in `src/lib/i18n/locales/en.json`. `src/lib/i18n/index.ts` handles locale detection, persistence, cross-window sync, single-pass interpolation, and date/number formatting; React components subscribe via `useI18n()`.

Locale resolution order: `?lang=` URL parameter → saved `ste-language` preference → browser languages → `en`.

## Adding or updating copy

1. Wrap full UI sentences in `tr('保存')` and add `"保存": "Save"` to `src/lib/i18n/locales/en.json`. Prefer complete sentences with placeholders (`tr('已选择 {{v0}} 项', { v0: count })`) over concatenating translated fragments.
2. Subscribe components that render translated text with `useI18n()`. Define module-level label maps with getters (`get label() { return tr('...'); }`), and use `useLocalizedMemo` when memoized display values read translated getters.
3. Keep persisted values and internal keys stable: translate statuses, categories, and tags only at render time, never when saving to the vault/IndexedDB, building export file paths, or matching internal filter keys.
4. Character cards, chat logs, custom tags, saved names, built-in writing prompts, and the embedded SillyTavern frontend's own localization remain independent of UI language switching.
5. Verify with `npm run i18n:check`, relevant Vitest suites, and `npx playwright test --config=playwright.production.config.ts`.

## Adding another language

Add its catalog under `src/lib/i18n/locales/`, register the locale code in `src/lib/i18n/index.ts` and `LanguagePicker.tsx`, extend `scripts/site/content.mjs` with reciprocal `hreflang` links, and cover switching and narrow-viewport layout in Playwright tests.
